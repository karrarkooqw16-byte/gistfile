CampusFlow — جاهز للرفع
========================
محتويات المجلد:
  server.js      الخادم (حسابات، بحث، رسائل، مكالمات، حفظ البيانات)
  public/        واجهة التطبيق (index.html)
  package.json   يخلي الاستضافة تشغّله تلقائياً (npm start)
  render.yaml    إعداد جاهز لـ Render
  data/          يُنشأ تلقائياً ويحفظ فيه الحسابات والرسائل (data.json)

الرفع على Render:
  1) ارفع محتويات المجلد (مو ملف الـ zip نفسه) على مستودع GitHub.
  2) Render > New + > Blueprint > اختر المستودع > Apply.
     (أو Web Service يدوي: Start Command = node server.js)
  3) بعد ما يصير Live افتح الرابط، وسجّل حساب باسم المستخدم karrar فيصير أدمن وموثق.

الرفع على VPS:  npm start   (المنفذ من المتغير PORT، الافتراضي 3000)

متغيرات اختيارية:
  PORT         منفذ التشغيل
  ADMIN_USERS  أسماء الأدمن مفصولة بفاصلة (الافتراضي karrar)
  DATA_DIR     مكان حفظ البيانات (الافتراضي ./data)

تنبيه الحفظ: القرص في خطة Render المجانية مؤقت، وتنمسح البيانات عند إعادة النشر.
للحفظ الدائم استخدم Render Disk (مدفوع) وخلّ DATA_DIR=/var/data، أو استضافة VPS.
كلمة السر لازم 6 أحرف أو أكثر.
